#  WorkFlow Pro

A professional and responsive **Task Management Web App** to organize tasks, manage deadlines, and track productivity. Built as a **Web Development Project for SkillCraft Technology**.

##  Features

* ➕ Add, ✏️ edit & 🗑️ delete tasks
* ✅ Mark tasks as completed
* 🗓️ Due dates, times & overdue alerts
* 🎯 Priority levels — Low / Medium / High
* 🏷️ Categories — Personal, Work, Study, Health & Others
* 🔍 Search, filter & sort tasks
* 📌 Pin important tasks
* 📝 Notes, tags & subtasks
* 🔄 Recurring tasks
* ⏰ Reminders & browser notifications
* 📅 Calendar view
* 🔥 Streak tracking & 🏆 achievements
* 📊 Productivity dashboard & progress tracking
* 🌗 Dark / Light mode
* 💾 LocalStorage data persistence
* 📤 Export & 📥 Import JSON backups
* 🔐 Local authentication
* 📱 Fully responsive design

## 🛠️ Tech Stack

**HTML5 • CSS3 • Vanilla JavaScript • LocalStorage • Font Awesome**

##  Run Locally

Simply open `index.html` in your browser.

Or use:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
